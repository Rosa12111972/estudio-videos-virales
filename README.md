# Estudio de Vídeos Virales

App gratuita para crear vídeos promocionales que combinan ganchos y estrategias de marketing para Reels, TikTok y YouTube Shorts.

- 19 nichos (inmobiliaria, restauración, moda, belleza, fitness, salud, tecnología, cursos, viajes, tienda online…)
- Ganchos y estructuras narrativas (AIDA, problema-solución, top 3, antes/después, oferta limitada…)
- Calidad 4K, Full HD o HD; formatos 9:16, 4:5, 1:1 y 16:9
- Duración de 10, 20 o 30 segundos, o ilimitada
- Funciona en el navegador, en móvil y ordenador: las fotos y vídeos no se suben a ningún servidor

Ábrela en `index.html` o publícala con GitHub Pages (Settings → Pages → rama `main`).
